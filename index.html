GenBI Assistant

An AI-augmented BI platform that lets non-technical users query enterprise data in natural language. An LLM-based NL2SQL engine reads the database schema through retrieval, then validates its own queries and corrects errors automatically.

Behind it sits a star-schema data warehouse and an ETL pipeline, with automatic chart generation, role-based access control and proactive anomaly detection on key indicators.
